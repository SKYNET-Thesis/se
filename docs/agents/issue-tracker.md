# Issue tracker: GitHub

Issues and specs live in SKYNET-Thesis/se.
Use `gh` with `--repo SKYNET-Thesis/se`.

- Publish a ticket: `gh issue create`.
- Read a ticket: `gh issue view <number> --comments`.
- List tickets: `gh issue list`.
- Change labels: `gh issue edit <number>`.
- Close a ticket: `gh issue close <number>`.

For multiline issue bodies and comments, write the text to a file
and use `--body-file`.

PRs as a request surface: no.
