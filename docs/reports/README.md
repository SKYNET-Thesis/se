# Bộ tài liệu phần mềm SO-101

Tài liệu canonical duy nhất cho team là [Tài liệu phần mềm tổng hợp SO-101](../progress/teleoperation-progress-and-test-plan.md). Nó đã gộp Software Design Document, Software Test Document, Software User Guide, roadmap và tiến độ implementation.

Các file SDD/STD/SUG trong thư mục này chỉ được giữ làm tham chiếu lịch sử. Không cập nhật chúng độc lập và không coi fake/offline test là hardware acceptance.
