# Troubleshooting

| Symptom | Safe first action |
| --- | --- |
| Wrong motion direction | Release clutch/Stop; verify mapping offline. |
| Lost phone/VR connection | Confirm Hold; reconnect, recenter, preflight. |
| Port busy/unknown | Do not guess; Find Port and reassign. |
| E-stop locked | Inspect robot, reconnect/recenter, preflight, then Unlock. |
