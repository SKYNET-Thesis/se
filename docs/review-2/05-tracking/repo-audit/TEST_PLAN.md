# Review 2 test plan

`T = 3F + W + S + N`.

- F=7: allocation; assignment delivery; attempts/immutable versions; submission/symbolic evaluation; physical orchestration; teacher assessment; feedback/reflection.
- W=4: WF-01…WF-04.
- S=13: allocate, replace, publish, start attempt, submit attempt, freeze version, persist submission, finish symbolic evaluation, start/finish experiment, activate/finish control session, record review evidence.
- N=7 applicable Registration categories: safety, reliability, reproducibility, portability, performance, deployment, data.

Minimum: `T = 3(7) + 4 + 13 + 7 = 45` traceable cases.

There are 45 core test files and more individual cases, but raw Jest/Pytest count is not treated as proof. Existing named suites were audited for cross-org/membership/role denial, allocation idempotency, draft/published visibility, attempt/submission scope, ProgramVersion immutability/exact provenance, teacher-only review/assessment, physical eligibility, safety mode and allocation enforcement. Acceptance still requires mapped automated evidence plus explicit manual exclusions for hardware.
